# 🚀 部署检查清单

在部署 rsxonhub 之前，请确保完成以下检查项。

## 📋 部署前检查

### 环境准备

- [ ] 服务器满足最低要求（2 CPU, 2GB RAM, 10GB 存储）
- [ ] 已安装必要的软件（Docker 20.10+, Docker Compose v2.0+）
- [ ] 防火墙已配置（开放端口 80, 443, 3000）
- [ ] DNS 记录已配置（如使用域名）

### 配置文件

- [ ] 已复制 `.env.example` 为 `.env.local`
- [ ] `AUTH_SECRET` 已生成并设置（至少 64 字符）
- [ ] `AUTH_USERNAME` 和 `AUTH_PASSWORD` 已设置（强密码）
- [ ] `DATABASE_URL` 已正确配置
- [ ] `.env.local` 未提交到 Git（已在 .gitignore 中）

### 数据库

- [ ] PostgreSQL 16.x 可用
- [ ] 数据库用户和权限已配置
- [ ] 数据库备份策略已制定
- [ ] 已测试数据库连接

### 安全

- [ ] 使用 HTTPS（生产环境必需）
- [ ] 防火墙规则已配置
- [ ] 定期更新计划已制定
- [ ] 监控和告警已设置

## 🎯 快速部署检查（Docker Compose）

```bash
# 1. 验证环境
docker --version
docker-compose --version

# 2. 检查配置文件
ls -la .env.local
cat .env.local | grep AUTH_SECRET  # 确认已设置

# 3. 启动服务
DB_PASSWORD=your_password ./deploy.sh start

# 4. 验证部署
docker-compose ps
curl http://localhost:3000/api/health

# 5. 检查日志
docker-compose logs --tail=50 app
docker-compose logs --tail=50 worker
```

**预期结果：**
- ✅ 所有服务状态为 "Up"
- ✅ 健康检查返回 `{"status":"ok"}`
- ✅ 无错误日志
